在绑定设备上操作

先用 CLI 登录。将该次 CLI 登录的令牌从标准输入提供给 bind（不是浏览器凭据），替换服务来源、设备 UUID 和两个本地目录。两种终端都可以使用以下参数：

filecloud library bind --server 'SERVER_ORIGIN' --library-id {{.ID}} --device-id 'DEVICE_UUID' --client-dir 'CLIENT_DIR' --worktree 'WORKTREE' --token-stdin
filecloud library status --client-dir 'CLIENT_DIR' --worktree 'WORKTREE'
filecloud library sync --client-dir 'CLIENT_DIR' --worktree 'WORKTREE'
filecloud library watch --client-dir 'CLIENT_DIR' --worktree 'WORKTREE' --interval 30s

仅在首次导入已有文件且远端为空时使用 --import-local。刷新凭据前先同步，再以相同参数和新令牌 bind。解绑用 library unbind 加同一对目录参数；普通文件保留。

以设备 status 的 Pending 和 NextCommand 为准。删除保护须核对本机统计与候选前缀；并发冲突会保留冲突副本，中断后用同一工作目录继续 sync。
